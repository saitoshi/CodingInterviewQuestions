### PYTHON - CHECK ODD OR EVEN 
 <b>PROBLEM</b>
 <br/>
 For a function called check_odd_even, determine whether the given input is odd or even. 
<br/>
<b>ANSWER</b>
 ```
def check_odd_even(number):
    if number % 2 == 0:
        return "Even";
    else:
        return "Odd"
 ```
